# Historical preRC4 release records

These files and evidence describe 0.14.0-preRC4 and earlier previews. They are
retained without reclassifying their recorded tests as fresh RC1 results.
The current release contract, testing handoff and validation report live one
level above. Some original relative source/interface references describe the
original preRC4 archive layout; current source interfaces remain above in
`../interfaces/`. The complete original preRC4 ZIP is retained separately.
