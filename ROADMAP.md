# Release roadmap

Current release: **1.0.0 stable**. Stable promotion is user-authorized. The latest user-tested game code is retained with stable version/menu labels.

Completed: event-driven deferred saving, phone/combat/native gating, optional Smart Autosave, manual presets, Dark Future notification contexts, neutral player notices, matched save-completion messages, current release tests, Windows auditor fixes and clean publication packages.

No new features were added during stable promotion. Backup/recovery tooling, automatic character profiles and every-safehouse trigger coverage remain outside scope. Future changes will be separately scoped.

Keep documented test/compatibility limits visible in VALIDATION.md and preserve previous downloads for rollback. Stable is the publication channel; it does not invent an unrecorded compatibility matrix.
